# resist.garden

A quiet page for the moment you open a new tab while an agent is working.
One garden, one breathing circle, nothing to scroll.

## Run locally

```sh
python3 -m http.server 8080
```

Then open <http://localhost:8080>.

## Structure

- `index.html` — the page
- `style.css` — all styling and animation
- `images/` — background photos

## Deploy

It is a static site. Any static host works (Cloudflare Pages, Netlify, GitHub Pages).
Point the host at this directory.
